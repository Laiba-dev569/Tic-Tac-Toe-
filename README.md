# Tic-Tac-Toe-
# 🎮 Tic Tac Toe Game (Python Tkinter)

A simple and interactive Tic Tac Toe game built using Python and Tkinter GUI.

---

## 🌊 Features
- Two-player game (X and O)
- Clean ocean-themed UI
- Win detection system
- Disabled buttons after win
- Easy and beginner-friendly code

---

## 🛠️ Technologies Used
- Python 🐍
- Tkinter (GUI library)

---

## 🚀 How to Run
1. Install Python
2. Run the file:
```bash
python tic_tac_toe.py
